# 🧟 Zombie Tasks

> Finish your tasks before they rise from the dead.

A Halloween-themed to-do list built for the **DevNexus Hackathon**. Add a task with a due time and keep it alive. If you miss the deadline, the task rises from the dead as a shaking red zombie, and you have to kill it.

**🔗 Live demo:** https://ananya07-web.github.io/Zombie-tasks/

---

## 🎃 The idea

Normal to-do lists stay quiet even when you are late. Zombie Tasks makes missed deadlines scary (and fun) so you actually finish what you start.

## ✨ Features

- 📝 Add tasks with a due date and time
- 🕯️ Tasks on time show a glowing candle
- 🧟 Overdue tasks turn into red, shaking zombies automatically
- 💥 Click **Done** (+5 points) or **Kill** a zombie (+10 points)
- 🏆 Zombie-killing score at the top of the page
- 💾 Tasks and score are saved in your browser (localStorage), so they survive a refresh
- 🦇 Spooky dark theme with the Creepster font and green glow

## 🚀 Run it locally

1. Clone the repo:
   ```
   git clone https://github.com/ananya07-web/Zombie-tasks.git
   ```
2. Open the folder in VS Code.
3. Right-click `index.html` and choose **Open with Live Server** (or just double-click the file).

## 📁 Project files

| File | What it does |
|------|--------------|
| `index.html` | Page structure |
| `style.css` | Spooky look and zombie animation |
| `script.js` | Task logic, zombie check, score and saving |
